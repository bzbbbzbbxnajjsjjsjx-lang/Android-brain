# Legacy View motion boundary

The Material Components Android motion theming document describes the View-based Material Components system. Use it only when maintaining that stack or as historical context for design intent. Do not copy XML theme attributes, View animators, or MotionLayout setup into Jetpack Compose. For Compose, verify current Compose/Material3 APIs and their version and accessibility behavior.

**Provenance:** `legacy_view_motion`, upstream Material Components Android documentation.
