# Button groups (View library)

The guide distinguishes standard and connected groups and describes the group as a container that arranges children and changes spacing/shape. Its Expressive section documents View-library additions and deprecates the older segmented-button naming in favor of connected groups. Press-size changes and XML style/attribute names are library implementation details at this pinned revision; they are not Compose APIs.
