# Navigation drawer (View library)

The guide describes standard/modal drawer variants and drawer anatomy. Its Expressive update says the View drawer is deprecated in favor of an expanded navigation rail. The View accessibility section covers labeled menu items, keyboard Escape closing, and labeled 48dp opening controls. Treat migration and measurements as statements in this pinned library document, not a Compose implementation recipe.

## Scope and implementation boundary

This is documentation for the Google-maintained **Material Components for Android Views/XML library** at repository revision `60ff09436d5d477a4b9d02940f31eb01e1250620`.
